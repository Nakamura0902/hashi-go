## 1. 空席バッジ 状態定義

すべての店舗カード・地図ピン・詳細画面で共通使用。

| 状態キー | ラベル | テキストカラー | 背景カラー | アイコン | 意味 |
|---------|-------|-------------|----------|---------|------|
| `open` | すぐ案内可 | `color-open` | `color-open-bg` | 緑丸● | 複数席即時空き |
| `few` | 残りわずか | `color-few` | `color-few-bg` | オレンジ●(点滅) | 1〜2席のみ |
| `soon` | もうすぐ空く | `color-soon` | `color-soon-bg` | 時計アイコン | 15〜30分後に空き予定 |
| `full` | 満席 | `color-full` | `color-full-bg` | ✕ | 現在案内不可 |
| `closed` | 営業時間外 | `color-closed` | `color-closed-bg` | 月アイコン | 閉店中 |

バッジサイズ: `radius-sm`、`12px/600`、横パディング `8px`、縦 `4px`。
`few` 状態のみ、バッジの左端に直径 `6px` の点を `animation-pulse` で点滅させる。

## 3. 画面① ホーム / 検索設定

### 画面の目的

ユーザーが現在地・人数・予算・雰囲気・目的を最小タップで入力し、「今すぐ探す」を押して即座に検索を開始できる。酔っていても迷わない、入力ステップ最小化が最優先。

### レイアウト構造（上から順）

```
┌─────────────────────────────────────┐
│  StatusBar（OS）                      │
├─────────────────────────────────────┤
│  A. ロゴ / キャッチコピーエリア            │  高さ約88px
├─────────────────────────────────────┤
│  B. 入力カード                          │  スクロール対応
│    B-1. 現在地セクション                  │
│    B-2. 人数セクション                    │
│    B-3. 予算セクション                    │
│    B-4. 雰囲気セクション                  │
│    B-5. 目的セクション                    │
├─────────────────────────────────────┤
│  C. CTA「今すぐ探す」ボタン               │  固定 or カード内最下部
├─────────────────────────────────────┤
│  D. ボトムナビ                           │  固定
└─────────────────────────────────────┘
```

### A. ロゴ / キャッチコピーエリア

- 背景: `color-secondary`（ネイビー）、角丸なし（画面幅全体）
- 上下パディング: `20px 16px`
- ロゴ「はしGO」: `28px / 800`、白、左寄せ。「はし」は細め、「GO」はオレンジ強調（`color-primary`）
- キャッチコピー「次、どこ行く？を10秒で。」: `13px / 400`、`rgba(255,255,255,0.75)`、ロゴ直下 `4px` 空けて配置
- 右端にオレンジの提灯アイコン（装飾用、24px）

### B. 入力カード

- 背景: `color-surface`、`radius-md`、`shadow-card`
- カード全体のマージン: `16px`（横）、`16px`（上）
- 各セクション間: `1px` の `color-border` 区切り線

#### B-1. 現在地セクション

- ラベル「現在地」: `13px / 600`、`color-text-secondary`、左寄せ
- GPS自動取得ボタン: `color-primary` の位置アイコン＋「現在地を使う」テキスト、`radius-full`、ボーダー `1.5px color-primary`、横幅100%、高さ `48px`
- GPS取得後: 住所テキスト（`14px`）に切り替わり、右端に「変更」リンク
- テキスト手入力リンク: `12px / color-text-muted`、ボタン下に「住所で入力する」

#### B-2. 人数セクション

- ラベル「人数」: `13px / 600`
- `-` ボタン / 数字表示 / `+` ボタン の横並びステッパー
- ボタン: `40×40px`、`radius-full`、`color-border` ボーダー、アイコン `20px`
- 数字: `24px / 700`、中央、最小1・最大20
- デフォルト: `2`

#### B-3. 予算セクション

- ラベル「予算 / 人」: `13px / 600`
- ピルタグ横スクロール: `〜1,000円` / `〜1,500円` / `〜2,000円` / `〜3,000円` / `〜5,000円` / `制限なし`
- 非選択: 白背景、`color-border` ボーダー、`color-text-secondary`テキスト
- 選択: `color-primary-light` 背景、`color-primary` ボーダー・テキスト
- ピルサイズ: `height 36px`、`radius-full`、`padding 0 14px`

#### B-4. 雰囲気セクション

- ラベル「雰囲気」: `13px / 600`
- 2列グリッド（各 `calc(50% - 6px)`）のタップカード
- 選択肢: 「にぎやか」「落ち着いた」「おしゃれ」「大衆酒場」「和モダン」（5つ、奇数なので最後は1列幅）
- 各カード: `height 44px`、`radius-sm`、センタリング、絵文字アイコン＋テキスト
- 非選択: `color-bg` 背景、`color-border` ボーダー、`color-text-secondary`
- 選択: `color-secondary` 背景、白テキスト

| 選択肢 | 絵文字 |
|-------|-------|
| にぎやか | 🍻 |
| 落ち着いた | 🕯️ |
| おしゃれ | ✨ |
| 大衆酒場 | 🏮 |
| 和モダン | 🍵 |

複数選択可。

#### B-5. 目的セクション

- ラベル「今夜の目的」: `13px / 600`
- 1列縦並びのラジオカード（単一選択）
- 選択肢6つ:

| 目的 | 絵文字 |
|-----|-------|
| まだ飲みたい | 🍶 |
| 安く飲み直したい | 💰 |
| しっぽり話したい | 💬 |
| 終電まで軽く | 🚃 |
| 深夜まで | 🌙 |
| 締めごはん | 🍜 |

- 各カード: `height 52px`、`radius-sm`、横並び（絵文字 + テキスト + 右端チェックマーク）
- 非選択: 白背景、`color-border` ボーダー
- 選択: `color-secondary` 背景、白テキスト、右端に `✓` マーク

### C. CTA「今すぐ探す」ボタン

- カードの下、ボトムナビの上に固定配置（`sticky bottom-[64px]`）
- 横マージン: `16px`、縦: `16px 0`
- ボタン本体: 横幅100%、`height 60px`、`radius-full`
- 背景: `color-primary`、テキスト: 白、`18px / 700`
- 影: `shadow-fab`
- 左端にサーチアイコン（白、20px）
- 未選択項目がある場合でも押せる（GPSのみ必須）
- ローディング時: スピナー表示 + テキスト「検索中...」

### インタラクション / 遷移

- GPS取得中: ボタン内に `animate-pulse` のインジケーター
- 「今すぐ探す」タップ → 画面② へ遷移（スライドアップアニメーション）
- ボトムナビ「地図」タップ → 画面③ へ遷移

### 余白・タイポ方針

- カード内の各セクション: 上下 `16px` の内部パディング
- ラベルとコントロールの間: `8px`
- カード間の外側ギャップ: `12px`

## 4. 画面② おすすめ一覧

### 画面の目的

検索結果の店舗一覧を空席状況・はしごスコア付きで表示し、「今すぐ入れる店」を素早く判断・選択できる。スクロールして比較し、気になる店の詳細へ遷移する。

### レイアウト構造（上から順）

```
┌─────────────────────────────────────┐
│  StatusBar（OS）                      │
├─────────────────────────────────────┤
│  A. ヘッダー                          │  固定
├─────────────────────────────────────┤
│  B. 絞り込みバー                       │  固定（ヘッダー直下）
├─────────────────────────────────────┤
│  C. 店舗カードリスト                    │  スクロール
│    C-1. 店舗カード（繰り返し）            │
├─────────────────────────────────────┤
│  D. ボトムナビ                          │  固定
└─────────────────────────────────────┘
```

### A. ヘッダー

- 背景: `color-secondary`
- 左: 戻るアイコン（白、24px） + 「おすすめのお店」`20px / 700` 白
- 右: 並び替えアイコン（白、24px）＋「並び替え」`12px` 白
- 高さ: `56px`
- 並び替えアイコンタップ: ボトムシートで「はしごスコア順（デフォルト）/ 距離が近い順 / 予算が安い順 / 空席が多い順」から選択

ヘッダー直下に `color-text-muted` の補足テキスト「現在の空席状況を反映しています」`12px`、背景`color-bg`、`8px` 上下パディング、横 `16px`

### B. 絞り込みバー

- 横スクロール可能なピルフィルター
- 項目: 「すべて」「空席あり」「徒歩5分以内」「予算〜1,500円」「深夜OK」「4名以上OK」
- 背景: `color-surface`、下端 `1px color-border`
- 各ピル: `height 32px`、`radius-full`、`padding 0 12px`、`12px / 600`
- 非選択: 白背景、`color-border` ボーダー
- 選択: `color-secondary` 背景、白テキスト

### C. 店舗カード（1枚の仕様）

カードマージン: 横 `16px`、カード間 `12px`

## 5. 画面③ 地図で探す

### 画面の目的

近隣店舗の位置関係を地図上で把握し、動線・距離感から直感的に行く店を決定する。現在地から「歩ける距離感」の把握が最優先。

### レイアウト構造（上から順）

```
┌─────────────────────────────────────┐
│  StatusBar（OS）                      │
├─────────────────────────────────────┤
│  A. 上部フィルターバー                  │  固定
├─────────────────────────────────────┤
│  B. 地図本体（Google Maps等）           │  縦に伸縮（flex-1）
├─────────────────────────────────────┤
│  C. 選択中店舗サマリーカード（任意）      │  固定（ボトムシート）
├─────────────────────────────────────┤
│  D. ボトムナビ                          │  固定
└─────────────────────────────────────┘
```

### A. 上部フィルターバー

- 背景: `color-surface`、下端 `shadow-card`
- 高さ: `52px`
- 横スクロールピルフィルター
- 項目: 「空席あり」「安め（〜1,500円）」「深夜営業」「4名OK」「徒歩5分以内」
- デザインは画面②の絞り込みバーと共通
- 現在地ボタン: フィルターバー右端に固定、`color-primary` ターゲットアイコン（「現在地に戻る」）

### B. 地図本体

- 地図はOS標準タイルまたは Mapbox / Google Maps
- 地図上の要素:
  - **現在地ピン**: 青い円＋外周に半透明の円（GPS精度表現）
  - **店舗ピン**: 下記仕様

**店舗ピンの仕様**

| ピン形状 | 内容 | サイズ |
|--------|------|-------|
| 角丸矩形バブル | 店舗名（最大6文字）＋空席バッジカラー背景 | `64×32px` |
| バブル下端 | 三角ポインター | `8px` |

- `open` 状態: `color-open` 背景、白テキスト
- `few` 状態: `color-few` 背景、白テキスト
- `soon` 状態: `color-soon` 背景、ダークテキスト
- `full` / `closed` 状態: `color-closed` 背景、白テキスト、不透明度60%

- 選択中ピン: `2px` 白アウトライン追加、`shadow-card-hover`、やや拡大（`scale: 1.15`）

- 地図タイルは夜間向けのやや暗めスタイル推奨（Mapbox dark-v11 を控えめにカスタマイズ、または明るいスタイルを使用）

### C. 選択中店舗サマリーカード

## 6. 画面④ 店舗詳細 / 行く

### 画面の目的

この店に行くかどうかの意思決定を完了させ、来店に向けたアクション（ナビ・QRチェックイン）を提供する。来店前の不安（満席リスク・場所・予算）をすべてここで解消する。

### レイアウト構造（上から順）

```
┌─────────────────────────────────────┐
│  A. ヒーロー画像エリア（スクロールに追従しない）│
├─────────────────────────────────────┤
│  B. スクロールコンテンツ                │
│    B-1. 基本情報ブロック               │
│    B-2. 席情報ブロック                 │
│    B-3. はしごスコア詳細ブロック         │
│    B-4. 特典ブロック                   │
│    B-5. 営業情報ブロック               │
│    B-6. QRチェックイン案内ブロック       │
├─────────────────────────────────────┤
│  C. 固定CTA「この店に行く」             │  固定
└─────────────────────────────────────┘
```

### A. ヒーロー画像エリア

- 高さ: `220px`、横幅全体、`object-fit: cover`
- 画像左上: 戻るボタン（`36×36px`、半透明白背景円、`radius-full`、戻る矢印アイコン）
- 画像右上: お気に入りボタン（同サイズ、ハートアイコン）
- 画像下端にグラデーションオーバーレイ（透明→黒 `40%` 不透明、高さ `80px`）
- グラデーション上に空席バッジを `absolute bottom-3 left-4` で配置

### B-1. 基本情報ブロック

- パディング: `16px 16px 0`
- 店舗名: `22px / 700`、`color-text-primary`
- 1行下に雰囲気タグ横並び（画面②と同仕様）
- 距離・時間行: 「📍徒歩X分（Xm）」、`color-text-secondary`、`14px`
- 予算行: 「💴 〜X,XXX円 / 人」、`color-text-secondary`、`14px`
- 営業時間行: 「🕐 XX:00 〜 XX:00（残りXX時間）」、`color-text-secondary`、`14px`

### B-2. 席情報ブロック

- セクション見出し「空席状況」: `15px / 600`、`color-text-primary`
- カード形式（`color-surface`、`radius-md`、`shadow-card`）で以下を3列グリッド表示

| 席タイプ | アイコン | 表示内容 |
|--------|---------|---------|
| 2名席 | 👥 | 空X席 / 全X席 |
| 4名席 | 👥👥 | 空X席 / 全X席 |
| カウンター | 🪑 | 空X席 / 全X席 |

- 各セル: `height 72px`、中央揃え、アイコン上段 `16px`、テキスト下段 `12px / 600`
- 空きあり: `color-open` テキスト、`color-open-bg` 背景
- 満席: `color-closed` テキスト、`color-closed-bg` 背景

### B-3. はしごスコア詳細ブロック

- セクション見出し「はしごスコア」: `15px / 600`
- スコア表示: 炎アイコン（`28px`、`color-primary`）＋数字 `40px / 800 color-primary`＋`/100`テキスト
- スコアバー: 横幅100%の `height 8px` `radius-full` のプログレスバー（`color-primary`）
- スコア根拠タグ横並び（例: 「📍近い」「✅空席多め」「💰予算ぴったり」「🎉特典あり」）
  - 各タグ: `color-primary-light` 背景、`color-primary-dark` テキスト、`radius-sm`、`12px / 500`

### B-4. 特典ブロック

- 特典がある場合のみ表示
- 背景: `#FFF7ED`（オレンジ極薄）、`radius-md`、`border 1.5px color-primary`
- 左端に🎁アイコン（`24px`）
- テキスト例: 「🎁 はしGO来店特典: 1杯目無料」、`14px / 600 color-primary-dark`
- サブテキスト: 「QRチェックイン時に適用」、`12px color-text-muted`

### B-5. 営業情報ブロック

- セクション見出し「お店の情報」
- リスト形式:

| アイコン | ラベル | 内容 |
|--------|-------|------|
| 🕐 | 営業時間 | XX:00〜XX:00（深夜対応可の場合「深夜X時まで」） |
| 📞 | 電話番号 | XXX-XXXX-XXXX（タップで発信） |
| 📍 | 住所 | 〇〇区〇〇X-X-X |
| 🚃 | 最寄り駅 | 〇〇駅から徒歩X分 |

各行: `height 44px`、アイコン `20px`、テキスト `14px`、右端に `>` の場合はタップ可

### B-6. QRチェックイン案内ブロック

- セクション見出し「チェックイン」
- 背景: `color-bg`、`radius-md`、`padding 16px`
- 説明テキスト: 「お店に着いたらQRコードをスタッフに見せてください。特典が適用されます。」`13px color-text-secondary`
- QRプレビュー: 画面内中央に `120×120px` のQR（来店意思確定後に表示）
- QR未表示時: ロック状態のプレースホルダー＋「「この店に行く」ボタンを押すとQRが表示されます」テキスト

### C. 固定CTA「この店に行く」ボタン

- `position: fixed`、`bottom: 64px`（ボトムナビ上）
- 横 `16px` マージン、縦 `16px` パディング、白背景で影を持つ帯
- ボタン: 横幅100%、`height 60px`、`radius-full`、`color-primary` 背景
- テキスト: 「この店に行く →」`18px / 700`、白
- アイコン: 左端に地図ピンアイコン（白、`20px`）
- 影: `shadow-fab`
- 押下後の状態:
  1. 「確認中...」スピナー（0.5秒）
  2. 「確定しました！」緑チェックアニメーション（0.5秒）
  3. QRコード表示 + マップアプリ起動の選択肢シート表示

### インタラクション / 遷移

- 「この店に行く」タップ → QR表示 + ナビ起動オプションシート
- ナビを選択 → OS標準マップアプリへディープリンク
- 戻るボタン → 前画面（一覧 or 地図）へ戻る
- お気に入りアイコン → 即時保存（ハートアニメーション付き）

## 8. 実装上の補足

### パフォーマンス考慮

- 店舗カード画像: `loading="lazy"`、`srcset` で 1x / 2x 対応
- 地図ピン: 画面内に存在する分のみレンダリング（仮想化）
- 空席状況: ポーリング or WebSocket で30秒ごとに更新

### アクセシビリティ

- 全ボタン: `min-height 44px`（iOS HIG 準拠）
- カラーだけで状態を伝えない: バッジはアイコン＋テキスト＋色を組み合わせる
- タップ対象の間隔: `8px` 以上

### アニメーション

| 場面 | アニメーション |
|-----|-------------|
| 画面遷移 | スライドアップ（`300ms ease-out`） |
| カード表示 | フェードイン＋わずかに下からスライド（`200ms`） |
| バッジ `few` 点滅 | `animation-pulse 2s infinite` |
| CTAボタン押下 | スケールダウン（`scale 0.97`、`100ms`） |
| お気に入り保存 | ハートのバウンスアニメーション |
| マップピン選択 | スケールアップ（`scale 1.15`、`150ms`） |
